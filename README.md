# Homebrew Terminal Workspace

Homebrew tap for [Terminal Workspace](https://github.com/EvanAI0331/terminal-workspace), a cross-project multi-terminal workspace for local development stacks.

## Install

```bash
brew tap EvanAI0331/terminal-workspace
brew install --cask terminal-workspace
```

Current macOS builds are ad-hoc signed and not notarized yet. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and approve Terminal Workspace.
